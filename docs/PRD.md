# StrategyLab MVP 产品需求文档

> 基于LLM的A股策略验证工具
> 版本：MVP v0.1
> 日期：2025-02-24

---

## 1. 产品概述

### 1.1 核心价值
让用户用自然语言描述交易策略，快速获得回测结果和优化建议，降低量化策略验证门槛。

### 1.2 目标用户
- 量化爱好者（有想法但不会写代码）
- 金融专业学生（学习策略构建）
- 初级研究员（快速验证假设）

### 1.3 使用场景
用户有一个策略想法（如"60日动量轮动"），通过对话澄清细节，系统自动回测并给出分析报告。

## 2. 功能模块

### 2.1 Playground（策略构建页）

#### 页面布局
```
┌─────────────────────────┬─────────────────────────┐
│      左侧：对话面板       │      右侧：实时预览       │
│                         │                         │
│  ┌─────────────────┐   │  ┌─────────────────┐   │
│  │ 消息历史         │   │  │ 策略结构卡片     │   │
│  │ - 用户输入       │   │  │ - 已确认要素     │   │
│  │ - 系统回复       │   │  │ - 待确认要素     │   │
│  └─────────────────┘   │  └─────────────────┘   │
│                         │                         │
│  ┌─────────────────┐   │  ┌─────────────────┐   │
│  │ 输入框           │   │  │ 代码预览         │   │
│  │ [发送]           │   │  │ （策略确认后显示）│   │
│  └─────────────────┘   │  └─────────────────┘   │
│                         │                         │
│  [清空对话] [查看示例]   │  [开始回测]            │
└─────────────────────────┴─────────────────────────┘
```

#### 对话流程

**第一轮：用户输入**
- 用户输入自然语言策略描述
- 示例："我想做一个动量策略，买入涨得最多的股票"

**第二轮：系统澄清**
系统识别缺失要素，逐项追问：

| 要素 | 追问示例 |
|-----|---------|
| 标的范围 | "请确认标的范围：全A股 / 沪深300 / 创业板 / 特定行业？" |
| 动量计算 | "动量计算周期：20日 / 60日 / 自定义天数？" |
| 调仓频率 | "调仓频率：日频 / 周频 / 月频？" |
| 持仓数量 | "持仓数量：前10只 / 前50只 / 自定义？" |
| 权重方式 | "权重分配：等权 / 市值加权 / 动量加权？" |
| 风控规则 | "是否设置止损：最大回撤止损 / 个股仓位上限 / 都不设？" |

**第三轮：用户确认**
用户逐项回复，系统实时更新策略结构卡片。

**第四轮：策略确认**
当所有要素确认完毕，系统展示：
- 完整策略结构（JSON预览）
- 生成的Backtrader代码片段
- 【开始回测】按钮

#### 边界处理

| 场景 | 处理 |
|-----|------|
| 用户输入模糊 | 给出选项让用户选择，而非开放回答 |
| 用户输入矛盾 | 提示矛盾点，给出修正建议 |
| 用户跳过必填项 | 标记为"使用默认值"，可后续修改 |
| 用户想修改已确认项 | 点击结构卡片中的编辑按钮，重新澄清 |

#### 页面布局
```
┌─────────────────────────────────────────────────────┐
│  [返回Playground]  策略名称  [分享] [重新回测]        │
├─────────────────────────────────────────────────────┤

│  ┌─────────────────────────────────────────────┐   │
│  │           核心指标卡片（4列）                 │   │
│  │  累计收益  |  年化收益  |  最大回撤  |  夏普比率  │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  ┌─────────────────┐  ┌─────────────────────────┐  │
│  │   收益曲线图     │  │    月度收益热力图        │  │
│  │   (Plotly)      │  │                         │  │
│  └─────────────────┘  └─────────────────────────┘  │
│                                                     │
│  ┌─────────────────────────────────────────────┐   │
│  │           交易统计表格                       │   │
│  │  总交易次数 | 胜率 | 盈亏比 | 平均持仓天数    │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
│  ┌─────────────────────────────────────────────┐   │
│  │           LLM解读与建议（报告B）              │   │
│  │  - 策略表现总结                              │   │
│  │  - 潜在风险点                                │   │
│  │  - 改进建议                                  │   │
│  └─────────────────────────────────────────────┘   │
│                                                     │
└─────────────────────────────────────────────────────┘
```

#### 报告A：数据指标

**核心指标**
| 指标 | 说明 |
|-----|------|
| 累计收益 | 策略期间总收益率 |
| 年化收益 | 年化复合收益率 |
| 最大回撤 | 峰值到谷底的最大跌幅 |
| 夏普比率 | 风险调整后收益 |

**风险分析**
| 指标 | 说明 |
|-----|------|
| 年化波动率 | 收益标准差年化 |
| VaR(95%) | 95%置信度下的单日最大损失 |
| 最大回撤持续天数 | 恢复所需时间 |
| 下行标准差 | 负收益波动率 |

**交易统计**
| 指标 | 说明 |
|-----|------|
| 总交易次数 | 买卖合计 |
| 胜率 | 盈利交易占比 |
| 盈亏比 | 平均盈利/平均亏损 |
| 平均持仓天数 | 持仓周期 |
| 换手率 | 年化换手率 |

#### 报告B：LLM解读与建议

**生成逻辑**
1. 将回测结果数据喂给LLM
2. 要求LLM从以下维度分析：
   - 策略表现是否符合预期
   - 存在的潜在问题（过拟合、幸存者偏差等）
   - 具体改进方向

**输出结构**
```
📊 策略表现总结
   - 一句话概括策略表现
   - 与基准（沪深300）对比

⚠️ 潜在风险点
   - 风险1：描述 + 数据支撑
   - 风险2：描述 + 数据支撑

💡 改进建议
   - 建议1：具体做法 + 预期效果
   - 建议2：具体做法 + 预期效果
```

## 3. 技术实现

### 3.1 系统架构

```
用户浏览器
    ↓
Next.js 前端 (Vercel)
    ↓
FastAPI 后端 (阿里云/腾讯云)
    ↓
├── LLM Service (DeepSeek API)
├── Backtest Engine (Backtrader)
└── Data Service (AkShare)
```

### 3.2 API 设计

#### POST /api/strategy/parse
解析用户输入，返回结构化策略或澄清问题。

**Request**
```json
{
  "message": "我想做一个动量策略",
  "conversation_id": "uuid",
  "current_params": {}
}
```

**Response - 需要澄清**
```json
{
  "status": "clarifying",
  "questions": [
    {"field": "universe", "question": "请确认标的范围...", "options": ["全A股", "沪深300"]}
  ],
  "current_params": {"factor": "momentum"}
}
```

**Response - 策略确认**
```json
{
  "status": "confirmed",
  "strategy": {
    "name": "60日动量轮动",
    "params": { ... },
    "code_preview": "..."
  }
}
```

#### POST /api/backtest/run
执行回测，返回结果。

**Request**
```json
{
  "strategy_params": { ... },
  "start_date": "2022-01-01",
  "end_date": "2025-01-01"
}
```

**Response**
```json
{
  "status": "success",
  "result": {
    "metrics": { ... },
    "equity_curve": [...],
    "trades": [...],
    "analysis": "LLM生成的解读文本"
  }
}
```

### 3.3 数据流

```
用户输入 → LLM解析 → 结构化参数 → 生成代码 → Backtrader执行 → 结果分析 → LLM解读 → 展示
```

## 4. 非功能需求

### 4.1 性能
- 回测响应时间 < 10秒（三年日线数据）
- 页面首屏加载 < 2秒

### 4.2 限制
- 单策略回测最大股票数：500只
- 历史数据范围：2022-01-01 至今
- 本地存储策略数上限：50条

### 4.3 安全
- 用户输入做SQL/XSS过滤
- LLM输出做敏感内容过滤
- 回测代码在沙箱执行
